# Meghan Fasano Career Site

A responsive, static career website built with HTML and CSS. It is ready for
GitHub Pages and does not require a build process, framework, database, or paid
hosting.

## Files

- `index.html` - Website structure and content
- `styles.css` - Responsive design, layout, and motion
- `Meghan_Fasano_Resume.pdf` - Downloadable résumé
- `favicon.svg` - Browser icon
- `.nojekyll` - Tells GitHub Pages to serve the files exactly as provided

## Publish with GitHub Pages

1. Create a new public GitHub repository.
2. Upload every file from this folder to the root of the repository.
3. Open the repository's **Settings**.
4. Select **Pages** in the left navigation.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select the `main` branch and the `/ (root)` folder.
7. Click **Save**.

GitHub will publish the site at:

`https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY-NAME/`

## Update the site

Edit `index.html` to change the wording or links. Edit `styles.css` to change
colors, spacing, and layout. Replace `Meghan_Fasano_Resume.pdf` with a new file
using the same filename whenever the résumé changes.

## Local preview

Double-click `index.html` to open it in a browser. For the most accurate preview,
run any simple local web server from this folder.
